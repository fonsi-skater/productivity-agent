# Fonsi Management System

An educational web app for managing contacts, tasks, and inventory with dummy
data. Everything runs locally in the browser and persists to localStorage.

## Features
- Contacts, tasks, and inventory dashboards
- Create, edit, delete, and search records
- Task completion toggles
- Local persistence with localStorage

## Run locally
Open `weather app/index.html` in your browser.

## Project structure
- `weather app/index.html` - layout and UI
- `weather app/styles.css` - styling and animations
- `weather app/app.js` - data logic and rendering
